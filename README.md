# 🎡 Glücksrad – Random Name Picker

Eine interaktive Wheel-of-Fortune-Web-App zum fairen Zufallsauswählen von Namen – direkt im Browser, ohne Installation.

## ✨ Features

- **Animiertes Glücksrad** mit bunten Segmenten im Wheel-of-Fortune-Stil
- **Namen hinzufügen & entfernen** – einer pro Zeile oder per CSV-Import
- **Konfetti-Animation** beim Gewinner
- **Gewinner-Historie** mit Zeitstempel (gespeichert via localStorage)
- **Sound-Effekte** (Dreh-Tick + Fanfare) mit Mute-Button
- **Responsiv** – funktioniert auf Desktop und Tablet

## 🚀 Verwendung

Einfach `index.html` im Browser öffnen – kein Server, kein Build-Schritt nötig.

1. Namen in die Liste eingeben (einer pro Zeile)
2. Auf **„Drehen!"** klicken oder `Leertaste` drücken
3. Gewinner wird groß angezeigt 🎉

## 🛠 Tech-Stack

- HTML5 · CSS3 · Vanilla JavaScript (ES6+)
- HTML5 Canvas API (Rad-Rendering)
- Web Audio API (Sound-Effekte)
- [canvas-confetti](https://github.com/catdad/canvas-confetti) via CDN
